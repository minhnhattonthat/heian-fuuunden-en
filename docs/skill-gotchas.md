# Skill gotchas (one line each: reference file, then the fact)

- SKILL.md Step 0: the plugin was enabled in `.claude/settings.json` but neither its skill nor its guard hook loaded in a dispatched (Orca) session; the `sed -i` canary passed until the hooks block was added to the project settings with the stable marketplace path.
- references/platform-snes.md: `lua/probes/snes_romreads.lua` logs one line per distinct (PC, bank), so it hides data streams; a per-(PC, 256-byte page) count (`tools/lua/readhist.lua` here) found the font loop at once. Its offsets also assume LoROM; on HiROM use `addr & 0x3FFFFF`.
- references/pipeline.md §Recon: a hot ROM-read loop during dialogue was the sprite builder, not text; filter histograms by the text banks first.
- references/graphics.md: menu captions here are raw BG3 tilemap words in ROM (`0x20xx`), not strings; searching the ROM for the low bytes of the dumped map row with a wildcard high byte (`54 . 35 . 5E . 58`) found the table when relative search found nothing.
- references/graphics.md §Survey: blocks stored back to back let a chain walker (decode, jump to the end, decode again; keep chains of ≥5) enumerate every compressed block without a pointer table; chains of 3 were noise in text and code banks.
- SKILL.md ground rules: with context-mode active, Bash output over ~4 KB and Read of files over ~4 KB come back as a stub; write to a file and Read with offset/limit, or filter in Python first.
- references/pipeline.md §Recon: system-font matching (MS Gothic, bbox-normalised NCC) identified only ~half of a 16×16 2bpp kanji font; read the sheets by eye.
- references/emulator-qa.md §emu.py: `STATE_OUT` is a driver global, so a `--var STATE_OUT=` for a warp script is rejected ("use NAME=LUA with a non-driver global name"); name the warp's own savestate var something else (`WARP_STATE` here).
- references/emulator-qa.md §Hooks: Mesen's Lua working folder was not `tools/mesen` here (`../debug/scenes.tsv` failed to open); derive repo paths from `OUT` or pass them absolute.
- references/emulator-qa.md §Debug tool: this game keeps its live state in SRAM and New Game writes slot 1 at once, so a warp = New Game -> edit slot 1 + checksum in Lua -> soft reset -> Continue; ~3 s per scene, no playthrough.
- scripts/dis65816.py: defaults to LoROM and prints nothing at all (exit 0) for a HiROM address like C0CB90; pass `--map hirom` (an empty-output warning would help).
- references/emulator-qa.md §Debug tool: a strategy-RPG battle here has its own state word (`$38`) under mode 7; route waits on the mode alone fired during the intro, before the player turn. Wait on the battle state word too (warp.lua `wait MM.SS.TT`).
- scripts/bps.py `snes_checksum`: plain sum is wrong for a 1.5 MB ROM (gave $803A, header says $F5A2); the mirrored sum (1 MB + 2 x 512 KB) matches. Fixed in this repo's `tools/bps.py` (`_mirrored_sum`); the skill copy still has the plain sum.
- references/pipeline.md §Identity: a game LZ whose original compressor breaks equal-length ties in no recoverable order (greedy farthest-first matched 187/426 blocks; hash-chain depth grid no better) - keep original packed bytes for unchanged blocks and gate the encoder on decode(encode(x)) == x over every block instead.
- scripts/tbl.py: for a 16-bit-word encoding, decode one word at a time (`decode(word_bytes, length=2)`); a whole-string decode escapes an unknown word as one byte and every later key matches misaligned.
- references/platform-snes.md §Assemblers: asar 1.91 refuses a ROM whose header title is half-width katakana ("looks like garbage"); pass `--no-title-check`. Its stdout is not UTF-8 on Windows: read it with `errors="replace"`.
- references/pipeline.md §Marker: a game whose glyphs carry a colour-2 paper (bp1 set in every row) needs the VWF to set bp1 = FF in each tile it touches, and to store (not OR) into a tile the first time it is touched so stale ink from an earlier string never survives.
- references/pipeline.md §Recon (code = font cell): ~860 kanji read by eye in 14 sheets (glyph x3 beside the system-font guess) went fast; checking every kanji used <=8 times in decoded context then caught 9 misreads (経/終, 柔/条, 抜/技 ...). Context-check the rare ones, not the common ones.
- references/platform-snes.md §Assemblers: asar 1.91 cannot forward-reference a `NAME = expr` define ("Label 'X' wasn't found"); give data a real label (`FONT8:` before its own incbin) instead of `FONT8 = FONT+$600` after the code that uses it.
- references/pipeline.md §Width gate: logging every call of the menu string renderer (caller, string id, VRAM slot; here `tools/lua/r2log.lua` on `C1:753B`) gives each name field's tile reserve from the VRAM step between slots in one warp run; it found a 3-tile party list among 6-tile fields that shots alone hid behind overflow.
- references/emulator-qa.md §Debug tool (free RAM for hooks): a "written at all" WRAM map is useless because boot and mode changes clear all RAM; log only non-zero writes (`tools/lua/wramuse.lua`, run beside warp.lua over many scenes) and take a long never-touched run.
- references/pipeline.md §Width gate: when a field is too narrow for any 16-px font, count VRAM tiles, not pixels: the renderer uploaded each 16-px slot as two half-rows; dropping the bottom DMA and drawing one 8-px row turned 3+3 tiles into 5 usable tiles (party list 24 -> 40 px).
- SKILL.md §Ground rules (read long files in parts): context-mode also stubs `cat`/`sed -n` output from Bash and small Reads of tables over ~4 KB; read docs with Read offset/limit or print a slice via python.
- SKILL.md §Ground rules (TSV edits): an Edit whose old/new string starts or ends at a tab can lose that tab (two scenes.tsv rows merged columns); anchor TSV edits on visible text on both sides, and keep the scene test that asserts the column count.
- references/emulator-qa.md §Debug tool: a warp route that soft-resets to the title needs `tap start until 03.03` (Start is ignored for a while after the title appears) and ~200 frames before the menu takes input; one too-early Down picked New Game instead of Continue.
- references/pipeline.md §Width gate: renderer-2 screens no tour reaches can be found statically from each `JSL` to the renderer (id = the immediate before `STA $1416`, VRAM = A); to force a runtime index (a place id) use an exec hook that pokes RAM at the PC that reads it (`tools/lua/execpoke.lua`).
